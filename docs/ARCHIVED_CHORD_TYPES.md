# Archived Chord Types

2026-07-01 時点で、公開アプリの通常UI・名前入力・判定候補から外したコード種類の控えです。

## 現役として残すコード種類

### 基本表示

- `maj`
- `min`
- `7`
- `m7`
- `maj7`
- `sus4`
- `add9`

### もっと見る

- `sus2`
- `7sus4`
- `dim`
- `dim7`
- `m7b5`
- `aug`

## アーカイブしたコード種類

- `6`
- `m6`
- `9`
- `m9`
- `mMaj7`
- `augMaj7`

## 理由

- J-POP / アニソン / ギター練習用途の初期公開範囲としては優先度が低いものがある。
- 可動フォームテンプレートの一部に、人間が押さえにくい、または指番号として破綻しやすい形が混ざっていた。
- 1つずつ外部サイト照合するには作業量が大きいため、まず現役コード種類を絞って品質を上げる。

## 扱い

- `src/app.js` の `TYPES`, `OPEN_SHAPES`, `movableTemplates` には、復活に備えてデータを残している。
- ただし `TYPE_ORDER`, `TYPE_GROUPS`, `TYPE_ALIASES` からは外し、通常UI・名前入力・構成音からの判定候補には出さない。
- 今後のフォーム妥当性調査は、現役13種類だけを対象にする。
- 分数コードは別機能として保留。実装する場合は、頻出形だけを手動データで追加する。
