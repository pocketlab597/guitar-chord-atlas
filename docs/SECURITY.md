# Security Notes

このMVPは静的Webアプリで、ログイン、ユーザー投稿、サーバー送信、決済を持たないため、一般的なWebサービスよりリスクは低い。

ただし、公開サイトとして以下は最初から守る。

## 初期MVPでの対策

- ユーザー入力をHTMLとして挿入しない
- 入力結果の表示は `textContent` を基本にする
- 外部依存を入れない
- 外部フォントを使わない
- `Content-Security-Policy` を設定する
- `form-action 'none'` でフォーム送信を禁止する
- `frame-ancestors 'none'` でクリックジャッキングを避ける
- localStorageには最近使ったコードだけを保存し、個人情報を保存しない

## 将来注意すること

- AdSenseや解析タグを入れる場合、CSPを見直す
- アフィリエイトリンクを入れる場合、リンク先と広告表記を整理する
- 問い合わせフォームを作る場合、スパム対策と送信先の扱いを別途設計する
- PWA化する場合、Service Workerのキャッシュ範囲を限定する
- URL共有機能を作る場合、URLパラメータをHTMLに直接反映しない

## 現時点で不要なもの

- パスワード管理
- 認証基盤
- CSRF対策
- サーバーサイドのレート制限
- 個人情報保護のためのデータ削除UI

これらは、ログインやユーザー送信を追加する段階で再検討する。
