# Design Direction

## コンセプト

ギター練習中に脳の負荷を増やさず、欲しいコード情報へすぐ届く道具。
「少ない操作で届く」「練習中に邪魔にならない」「また使いたくなる軽さ」を最優先する。
ランディングページではなく、毎日開く実用ツールとして設計する。

参考の質感: Nani / Zenn のような軽い日本製Webサービス感（淡い背景 + 白い作業面 + 余白 + 少しの遊び心）。
ただし模倣ではなく、設計原理（2層コントラスト / アクセント1色 / 線で仕切る / 控えめな角丸）だけを採用する。

## Visual

- 2層構造: 淡い寒色の背景（`--bg #f4f6f9`）の上に純白の作業面（`--surface #ffffff`）。
- アクセントは少し温かい青 1色（`--accent #4c8dff` / 選択は `--accent-weak #eaf2ff`）。
- 黄色（`--pop #ffce4a`）は「ルート/お気に入り」程度の極小ポイントだけ。ベースや背景には使わない。
- 影は限りなく弱く、面の仕切りは 1px の実線ボーダーで行う。
- 角丸はカード 14px / 入力・行 10px、チップとタブのみ pill（999px）で可愛げを担当。
- フォントウェイトは抑える: 本文 400 / ラベル・チップ 600 / 見出し 700 / コード名のみ 800。
- やめたこと: 黄色のベタ背景・radialグロー / 半透明ガラス + blur の濫用 / 巨大ドロップシャドウ / 英大文字eyebrow / 特大H1ヒーロー。

## Layout

- PC（>= 760px）: 上部にタブ（検索 / キー / 判定）。本体は2カラム = 左に入力・選択、右に結果（sticky で常に視界に残す）。幅は最大 1120px。
- スマホ（< 760px）: 単一カラムで入力→結果の縦積み。下部固定ナビ（3タブ）を維持。
- 下部固定ナビは `position: fixed` + `env(safe-area-inset-bottom)` で iPhone ホームバーに対応。PCでは非表示。

## 情報設計 / UX

「何のサイトか」は文章ではなく、主役の操作と初期表示で伝える。

- 各画面のタイトルは抽象語（調べる）ではなく価値で言い切る:
  「コードの押さえ方」「キーの中のコード」「音からコードを調べる」。
- 押さえ方画面の優先順位:
  1. 主役 = ルート × 種類のピッカー（2タップで押さえ方が出る）。
  2. 補助 = 「名前で入力」（コード名のみ。小さく控えめに）。音名はここでは受け付けない。
  3. ショートカット = 履歴。履歴があれば「最近見たコード」、無ければ「よく使うコード（定番）」。
     コントロールと混同させないよう、最下段＋区切り線＋淡いチップで軽く扱う。
- 初期表示は誰でも知っているコード（オープン C メジャー）にする。馴染みの指板図が
  「コードの押さえ方サイト」だと一瞬で伝える。珍しいコード（Eaug 等）を初期値にしない。

## レイアウト詳細

- 各画面は input / result / aux(履歴) の3ペイン。
- PC: 結果ペインを右カラムに固定（sticky）し、左カラムに input → aux を縦積み。
- スマホ: input → result → aux の順（ピッカー直下に結果）。履歴/定番タップ時のみ結果へスクロール。

## ギターを弾きながら使う前提

「弾いている最中はデバイスをできるだけ触りたくない」を最優先の制約とする。

- 構成音は頭を使わせない。指板図の各弦の左に音名を直接表示し（低音弦から E C G… のように）、
  どの弦が何の音かを一目で分かるようにする。役割（度数）はドットの色で示す。
- 下部の構成音表示は弦ごとの重複を出さず、コードを構成するユニークな音だけを
  「色ドット + 音名 + 役割（ルート / 長3度 …）」で並べる。`R / ルート` のような記号と語の重複はしない。
- ルートは12音すべて選べる（C C# D Eb E F F# G Ab A Bb B）。半音が選べないと実用にならない。
- キー画面は、毎回タップして開かなくても全ダイアトニックの押さえ方を一覧表示する。
  情報過多になりすぎないよう「押さえ方を表示」トグルでダイアグラムの表示/非表示を切り替えられる。
  キー内の音名は半音の綴りをスケール基準で正しく出す（例: Eキーは G#、Ab ではない）。
- 種類チップはホバー/長押しで正式名（メジャーセブンス 等）を出し、画面上の文字量は増やさない。

## 表記 / コード種類

- コード表記は muuu.jp 準拠。メジャー7=`M7`（CM7）、マイナーメジャー7=`mM7`、ハーフディム=`m7♭5`、
  オーギュメントメジャー7=`augM7`。`maj7` 等の別名でも入力は受理する。
- `M7`（メジャー7）と `m7`（マイナー7）は大文字小文字だけが違うため、名前入力のパースは
  小文字化せず大小を区別する（`TYPE_ALIASES` で照合）。
- 種類は全19種を扱うが、平坦に並べず「よく使う / セブンス・6th / テンション / sus・aug・dim」の
  小見出しで塊化して表示する（隠さず1タップのまま、走査の負荷だけ下げる）。
- 注意: `mMaj7` / `augMaj7` の押さえ方は公開版に専用データが無く、標準ボイシングを暫定で配置している。
  音楽データは要検証（本人のCAGEDエンジン等で差し替え前提）。

## ストック

- 練習する進行（例: FM7 G7 Em7 Am7）を覚える前に、一画面で押さえ方を見比べるための機能。
- 押さえ方画面の結果に「＋ ストック」。専用「ストック」タブに全コードをミニ図のカードで一覧。
  個別に × で外す。タブに件数バッジ。`localStorage` で保持。
- 「クリア」はストック全消去として機能させる（併せて入力欄もリセット）。

## MVP Screens

- 押さえ方: ルート×種類の2タップ、または名前入力で `CM7` などの押さえ方＋構成音を表示
- キー: 選んだキーのダイアトニックを、押さえ方つきで全コード一覧表示（トグルで名前のみにも）
- 判定: `ドミソ` などの構成音から候補を表示
- ストック: 複数コードをためて一画面で押さえ方を見比べる

## 注意

- コードフォーム/指板図の音楽データ・ロジックは既存実装を正とする。UI側で配色や見た目だけを調整し、押さえ方データは変更しない。
