# Chord Atlas Public MVP

ギター練習中に、コードの押さえ方・キーの中のコード・音からのコード判定をすぐ確認するための公開版MVPです。

## 現在の機能

- 押さえ方: ルートと種類の2タップ、またはコード名入力で指板図と構成音を表示
- キー: 選んだキーのダイアトニックコードを押さえ方つきで一覧表示
- 判定: `ドミソ` / `C E G` などの構成音からコード候補を表示
- ストック: 練習したい複数コードをためて一画面で見比べる

## 公開方針

- ログイン、ユーザー投稿、サーバー保存なし
- 広告、解析、外部フォントは初期MVPでは入れない
- localStorageには最近見たコードとストックだけを保存する
- 音楽データは公開後に段階的に監査し、必要に応じて修正する

## ローカル確認

静的ファイルだけで動きます。本番に近く確認する場合:

```powershell
python -m http.server 8787 --bind 127.0.0.1
```

その後 `http://127.0.0.1:8787/#lookup` を開きます。

## デプロイ

静的サイトとしてそのまま配信できます。GitHub Pages、Netlify、Vercel、Cloudflare Pages などでビルドコマンドなし・公開ディレクトリをリポジトリルートにすれば動きます。
