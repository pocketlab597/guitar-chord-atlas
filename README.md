# Chord Atlas Public MVP

ギター練習中に、コード検索・キーのコード・音から判定をすぐ使うための公開版MVPです。

## 方針

- 画像生成の指板図は使わず、既存ロジック由来のコードフォームとSVG描画を使う
- モバイルファースト
- 下部ナビで `検索 / キー / 判定` を切り替える
- ログイン、投稿、サーバー保存なし
- 広告、解析、外部フォントは初期MVPでは入れない

## ローカル確認

静的ファイルなので、そのまま `index.html` を開けます。

より本番に近く確認するなら:

```powershell
python -m http.server 8787 --bind 127.0.0.1
```

その後 `http://127.0.0.1:8787/` を開きます。
